## Reporting a vulnerability

Please report security problems **privately**, not as a public issue.

- Preferred: GitHub's [private vulnerability reporting](https://github.com/Ollornog/EightPerDay/security/advisories/new)
- Alternatively by e-mail: eightperday-github@ollornog.de

Please include what you did, what you expected and what happened instead, plus the version or commit you
tested.

## What you can expect

- **An acknowledgement within 14 days.** This project is maintained by one person in their spare time.
- An assessment of the report and, if confirmed, a fix or a documented mitigation.
- Credit in the release notes, unless you prefer otherwise.

## Supported versions

While the project is below 1.0, only the latest state of `main` and the latest release receive fixes.

## Scope

EightPerDay holds working times, absences and earnings, which are personal data and can reveal health data (sickness).
Reports about these are especially welcome:

- Reading or changing another person's or tenant's entries, also through an embedding application's row-level security.
- Changing a booked time without a trace in the correction history.
- Wrong results of the calculations (balance, leave, earnings) that someone could exploit.
